# Last Call

An idle bar-management game in pixel art. Run a lemonade stand, grow it into a global chain, and keep your guests happy.

- Play: open `index.html` in a browser. Progress is saved in `localStorage`.
- Code: edit `src/`, then `node build.js` to regenerate `index.html` (no dependencies).
- Develop with Claude Code: start with `CLAUDE.md`, then `docs/FIRST_PROMPT.md`.
- Test the economy: `tools/` (needs Python and Playwright, see `CLAUDE.md`).
